## 1. Project Overview

The Online Movie Ticket Booking System is a web-based application designed to provide users with a simple and convenient interface for exploring movies and selecting seats for a show.

The application contains a movie listing page with movie information and category filters, along with a ticket booking interface that allows users to select seats, choose a date, and select a showtime.

The project demonstrates the application of fundamental web development technologies to create an interactive and visually appealing movie ticket booking interface.

## 2. Objectives

The main objectives of this project are:

* To develop a user-friendly movie ticket booking interface.
* To display movie information in an organized layout.
* To provide movie category and language filters in the interface.
* To create an interactive seat-selection layout.
* To allow users to select a show date and time.
* To demonstrate the practical application of HTML, CSS, and JavaScript.

## 3. Technologies Used

| Technology | Purpose                                                                    |
| ---------- | -------------------------------------------------------------------------- |
| HTML5      | Structures the web pages and booking interface.                            |
| CSS3       | Provides styling, layout, colors, and visual effects.                      |
| JavaScript | Generates seat elements dynamically and updates the selected ticket count. |

## 4. Features

### 4.1 Movie Listing Page

* Displays a collection of movies.
* Includes an upcoming movie section.
* Provides a navigation bar for accessing page sections.
* Presents movie information in a structured layout.

### 4.2 Movie Filters

* Provides category options such as action, adventure, comedy, animation, and thriller.
* Includes language selection options.
* Provides morning and night show filters in the interface.

### 4.3 Seat Selection

* Displays a visual arrangement of cinema seats.
* Differentiates available, booked, and selected seats.
* Allows users to select seats using checkboxes.
* Dynamically generates additional seat elements using JavaScript.
* Updates the ticket count when seats are selected or deselected.

### 4.4 Date and Showtime Selection

* Provides date selection options.
* Displays multiple showtimes.
* Allows users to select a preferred date and showtime.

### 4.5 User Interface

* Uses a modern layout with contrasting colors.
* Includes styled buttons, movie cards, and booking components.
* Uses Google Fonts and Material Icons to enhance the interface.

## 7. Installation and Execution

Follow these steps to run the project locally.

**Step 1:** Download or extract the project ZIP file.

**Step 2:** Open the extracted project folder in Visual Studio Code or another code editor.

**Step 3:** Verify that the following files are present:

* `Book.html`
* `ticket.html`
* `styles1.css`
* `styles2.css`

**Step 4:** Open `Book.html` in a web browser.

**Step 5:** Explore the movie listing interface and navigate to the ticket booking page.

**Step 6:** Select seats, choose a date, and select a preferred showtime to explore the booking interface.

No backend server or database setup is required to run this front-end prototype.

## 8. Working Principle

The application works through the following sequence:

1. The user opens the movie listing page.
2. The user explores the available movie information.
3. The user navigates to the ticket booking interface.
4. The booking page displays a cinema seating layout.
5. JavaScript generates additional seat elements dynamically.
6. The user selects or deselects seats.
7. The selected ticket count is updated.
8. The user chooses a date and showtime.
9. The user can interact with the booking interface.

## 10. Limitations

The current project is a front-end prototype. It does not implement a complete production-ready ticket booking service.

* User authentication is not implemented.
* Movie information is not retrieved from a backend database.
* Seat availability is not synchronized across multiple users.
* Payment gateway integration is not implemented.
* Booking details are not persistently stored in a database.
* The booking button does not establish a verified reservation.
* The movie filters and external resources may require further integration or testing.
